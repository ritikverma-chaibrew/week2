Connect the AI

Touch Grass Tales uses Google's Gemma AI to write. You set it up once, in about 2 minutes. Pick one option:

☁️ Google AI Studio

Free key from Google. Works on any phone or computer.

  • Nothing to install
  • Key kept in your browser's local storage for 5 hours
  • About 2 to 4 minutes per tale
 For tinkerers

💻 LM Studio

Runs Gemma on your own computer. No key, no limits.

  • Needs the LM Studio app and a good PC
  • Works offline once models are downloaded
  • Speed depends on your computer

☁️ Google AI Studio

  1. Open aistudio.google.com/api-keys, sign in with Google, and press Create API key. Copy the key (it starts with AIza).
  2. In the Connect & test box below, choose Google AI Studio, paste the key and press Save key.
  3. Press Connect. When you see ● Connected, you're done. Create your first tale →
Good to know

Your key is kept in your browser's local storage for 5 hours, then deleted automatically. The server never stores it. If Google is busy, the app tries again automatically. A tale takes about 2 to 4 minutes. The AI never writes everything in one go: it looks at each photo, plans, writes one short part at a time and then proofreads, which keeps the writing focused.

💻 LM Studio (on your computer)

  1. Install LM Studio.
  2. In Discover, download a vision-capable Gemma (Gemma 3 4B/12B/27B or a Gemma 4 build). A bigger model writes better stories.
  3. Open the Developer tab, load your model and switch Start Server on (http://localhost:1234).
  4. In the Connect & test box below, choose LM Studio and press Test connection.

The Touch Grass Tales server must run on the same computer as LM Studio. Under Advanced settings you can pick which loaded Gemma model does each task.

🔌 Connect & test

Something not working?

"rejected your API key"

The key is wrong or expired. Create a new one at aistudio.google.com/api-keys and paste it again.

"Key disconnected"

Keys are removed from your browser's local storage after 5 hours for your safety. Paste your key again and press Connect.

Rate limit or daily limit

Google's free tier has limits. Wait a minute and press Retry.

"LM Studio server not reachable"

Start the server in LM Studio's Developer tab and check the URL (usually http://localhost:1234/v1).

"can't read images"

The "Look at each photo" task needs a model with vision (image) support.

Technical details: which model does what

Each task uses a different model on purpose: the large dense model for writing and editing, and the fast mixture-of-experts model for looking at photos and planning.

TaskDefault (Google AI Studio)Why
Look at each photoGemma 4 26B-A4BFast; one small (384px) photo at a time
Plan the story, poem or comic and pick the picturesGemma 4 26B-A4BFast, structured planning; chooses the photo for each moment
Write each scene or stanza, review, fix weak spotsGemma 4 31BBest prose and rhyme, in small pieces (about 170 words or 4 lines at a time)
Write comic panel wordsGemma 4 26B-A4BFast; a caption and up to 2 speech bubbles per panel
Hosting the app yourself (for developers)
  1. Install Python 3.11+ and start MongoDB locally on port 27017.
  2. pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
  3. Open http://localhost:8000.

To use MongoDB Atlas, put your mongodb+srv://… string in .env as MONGODB_URI and restart.
